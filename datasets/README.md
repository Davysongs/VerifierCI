# Datasets

Curated synthetic/provisional diagnostic fixtures and manifests for verifier audit pilots are stored here.

- `manifests/retry-contract-snapshot-v1.json`: Pinned SHA-256 trusted fixture digests (snapshot, contract, verifiers, patch diffs, and counterexample witnesses) checked by `verifierci.snapshots.SnapshotRegistry`.
- `sample-panels/sample-five-case.jsonl`: Synthetic five-case JSONL sample panel aligned with `examples/retry-contract/` (`review_status: provisional`, `diagnostic_only: true`).
- `provenance/`: Collection lineage and exposure tracking.
